# Starter addon v1.28.1

Changes since v1.26.0:
- Hedgehogs now spawn much more often (bigger flocks, higher weight) in forest, taiga, savanna and plains.
- The pack names now include the version number ("Starter BP 1.28.1" / "Starter RP 1.28.1"), so you can tell old and new versions apart in Minecraft.

To update: import this file, then in Settings > Storage delete the older "Starter" packs. In an existing world, remove the old packs from the world and add the new ones again (or just create a new world).

Minecraft Bedrock addon with a hedgehog, a thorn shield, a slingshot and spike traps.

## Install
- **Windows / Android / iOS:** download `starter.mcaddon` and open it with Minecraft.
- Create a new world, and enable both **Starter BP** (behavior pack) and **Starter RP** (resource pack).
- Requires Minecraft Bedrock 1.26 or newer.

### Android tip
On some Android devices (for example Samsung tablets), tapping the downloaded file does not offer Minecraft, only Google apps. If that happens:
1. Install [Cx File Explorer](https://play.google.com/store/apps/details?id=com.cxinventor.file.explorer) from Google Play.
2. Open the Downloads folder in Cx File Explorer and tap `starter.mcaddon`.
3. Choose **Minecraft** when asked which app to open it with.

## What is in it
| Name | What it does |
|---|---|
| Hedgehog | Neutral animal that spawns in forest, taiga, savanna and plains. Fights back. Drops spines. |
| Hedgehog Spine | Crafting ingredient dropped by hedgehogs |
| Hedgehog Ball | Slingshot ammo (4 spines in a 2x2 square makes 2) |
| Slingshot | Right-click to shoot hedgehog balls |
| Thorn Shield | Hold in off hand. Attackers take thorn damage, more if you sneak |
| Spike Trap | Damages anything standing on it |
| Poison Spike Trap | Spike trap with poison |
| Camouflaged Spike Trap | Invisible spike trap |
| Ruby Block | Decorative glowing block |
| Hedgehog Handbook | In-game guide, given automatically the first time you join a world |

Names and the handbook are available in English and Swedish.
